# Synx 0.2.0

Synx 0.2.0 is a pre-release. The compiler and standard library can change
before 1.0.

## Changes since 0.1.0

- The C++ compiler source is retired. Builds start with the checksum-pinned
  Synx 0.1.0 release and check that self-hosted compiler objects match.
- Match coverage checks and binding or-patterns.
- Owned trait objects through `Box<dyn Trait>`.
- Iterators, collection adapters, slicing, user-defined indexing, and
  optional field and call access through `?.`.
- `synx run` keeps native build outputs in a private per-user cache.
- Standalone builds include the Synx runtime. `--shared-runtime` retains
  the separate runtime library option.
- `synx lsp` provides live diagnostics, hover, definitions, references,
  completion, signature help, rename, and formatting.
- `synx fmt` provides in-place formatting, `--check`, `--stdout`, and
  `--stdin`. It uses four spaces and same-line braces.
- VS Code extension 0.2.0 uses the language server and supports Format
  Document and format on save.
- Windows packages include a graphical per-user installer.

## Packages

- Windows: `synx-0.2.0-windows-x86_64-setup.exe` and
  `synx-0.2.0-windows-x86_64.zip`.
- Linux: `synx-0.2.0-linux-x86_64.tar.gz`. Requires glibc 2.34 or later.
- macOS: `synx-0.2.0-macos-x86_64.tar.gz`. Requires macOS 10.15 or later;
  Apple Silicon uses Rosetta 2.
- VS Code: `synx-0.2.0.vsix`. Install it with
  `code --install-extension synx-0.2.0.vsix --force`, then reload VS Code.
- `SHA256SUMS` contains the checksums of the release assets.

The release workflow builds and tests Windows, Linux, and macOS before it
attaches packages to the release. Local Windows/Linux validation covers all 43 compiler suites,
bootstrap equality, formatter and language-server checks, and package
installation. The workflow provides the macOS validation for this update.

See [installation](https://github.com/EdwardWare06/synx/blob/v0.2.0/docs/guide/install.md),
[compiler commands](https://github.com/EdwardWare06/synx/blob/v0.2.0/docs/guide/commands.md), and
[formatting](https://github.com/EdwardWare06/synx/blob/v0.2.0/docs/guide/formatting.md). Marketplace publishing of the extension is
separate from this GitHub release.
