# Synx 0.3.0

Synx 0.3.0 is a pre-release. The compiler and standard library can change
before 1.0.

## Changes since 0.2.0

- Myelin provides `synx new`, `synx add`, `synx fetch`, and project
  build/run/check commands. Projects use `synx.toml`, pinned `synx.lock`
  files, path or Git dependencies, and offline/locked modes.
- Linux source debugging uses DWARF 4, including GDB discovery of standalone
  code, source breakpoints, stepping, and caller-frame register recovery.
- Windows emits CodeView in COFF objects and matching deterministic PDB files.
  Standalone debug code uses mapped PE sections with native unwind records.
- Both platforms describe parameters, locals, arrays, concrete struct and enum
  layouts, recursive owning types, and stack/register locations. Debug records
  track initialization, moves, scope ends, register reuse, and control flow.
- `-g` enables debug information, including with `--release`.
  `--no-debug` omits it. Linux and Windows debug builds enable it by default.
- Panic terminates immediately with status 101 without C exit hooks or DLL
  detach cleanup, including panics from worker threads.

## Packages

- Windows: `synx-0.3.0-windows-x86_64-setup.exe` and
  `synx-0.3.0-windows-x86_64.zip`.
- Linux: `synx-0.3.0-linux-x86_64.tar.gz`. Requires glibc 2.34 or later.
- macOS: `synx-0.3.0-macos-x86_64.tar.gz`. Requires macOS 10.15 or later;
  Apple Silicon uses Rosetta 2.
- The unchanged VS Code extension remains `synx-0.2.0.vsix`.
- `SHA256SUMS` contains the checksums of the release assets.

The release workflow builds and tests Windows, Linux, and macOS before it
attaches packages. The debug implementation passed all 48 suites locally on
Windows and Linux, including bootstrap equality and native debugger checks.
Linux allocation checks report no leaks. GitHub CI supplies macOS validation.
The compiler bootstraps from the checksum-pinned Synx 0.2.0 release.

macOS debug output, closure captures, and suspended async-frame inspection
remain separate work. See
[debugging](https://github.com/EdwardWare06/synx/blob/v0.3.0/docs/guide/debugging.md),
[projects and dependencies](https://github.com/EdwardWare06/synx/blob/v0.3.0/docs/guide/packages.md),
and [installation](https://github.com/EdwardWare06/synx/blob/v0.3.0/docs/guide/install.md).
