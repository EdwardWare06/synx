# The Synx tutorial

This tutorial teaches Synx to programmers who know another language, such as
Java or Python. Each chapter is short and shows each idea with a complete
program and its output. Read the chapters in order. Chapters 7 and 8 explain
ownership and borrowing, which have no direct match in Java or Python.

Install Synx first. See [Installing Synx](../install.md) and
[Getting started](../getting-started.md).
